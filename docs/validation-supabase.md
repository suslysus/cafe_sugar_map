# Supabase 로그인·마이페이지 검증

검증일: 2026-11-03. 화면 검증 담당: Luna low. 실제 DB와 브라우저 모의 검증의 범위를 구분한다.

## 실제 Supabase 프로젝트

- Project URL의 Auth 설정 조회 HTTP 200. Email 로그인·회원가입 활성화, 이메일 인증 유지 확인.
- profiles/favorites 생성, RLS 활성화, 각각 정책 2개/3개, anon SELECT 권한 없음 확인.
- `supabase/tests/rls.sql` 실제 실행 통과: 본인 프로필 조회·이름 수정, 본인 즐겨찾기 저장·삭제, 타인 행 조회·수정·삭제·대리 저장 차단, 프로필 소유자 컬럼 변경 차단, anon 조회 차단.
- SQL 테스트의 임시 사용자·프로필 모두 ROLLBACK되었음을 결과에서 확인.
- 실제 공개 키로 비로그인 profiles/favorites 조회가 HTTP 401 / Postgres 42501로 거부됨을 확인.
- 최초에는 Site URL localhost:8000을 사용했다. 이후 Pages 배포에 맞춰 Site URL을 `https://suslysus.github.io/cafe_sugar_map/mypage.html`로 바꾸고 같은 배포 주소와 두 로컬 mypage Redirect URL 총 세 개를 유지했다.

## 기존 Supabase 연동의 격리된 브라우저 검증

Playwright + Edge headless, Supabase SDK fixture, 데스크톱·모바일 검사 **81개 통과**, 콘솔·페이지 오류 0건. 테스트 중 외부 요청은 0건이며 실제 사용자·비밀번호·메일을 사용하지 않았다.

주요 검사: 로그인·가입·인증 대기·메일 재발송 안내·요청 제한, 비밀번호 복구 화면과 비밀번호 확인, 프로필 이름 편집·XSS 문자열 텍스트 처리, 즐겨찾기 저장·삭제·새로고침·계정 격리·지연 응답, 목록 오류 후 재시도와 배너 해제, 외부 returnTo 차단, 잘못된 키/URL·설정 누락·SDK 누락 시 차단, 복구 중 계정 전환, 네 페이지 이동과 모바일 가로 넘침.

공식 SDK를 대체하지 않은 별도 smoke 검사에서도 빈 브라우저 컨텍스트의 실제 번들 로드·Auth 초기화·로그인 폼 활성화·사용자 null 상태를 확인했다. 콘솔 오류와 외부 요청은 없었다. 이 검사는 실제 로그인을 시도하지 않는다.

## 별도 실제 계정 확인

이번 이메일 우선 가입 흐름은 배포 후 본인 이메일 입력 → 인증 메일 받기 → 같은 브라우저로 링크 확인 → 이름·비밀번호·확인 입력 → 회원가입 완료 → 로그아웃·비밀번호 로그인 순서로 확인한다. 메뉴 즐겨찾기 저장 → 마이페이지 조회 → 새로고침·다시 로그인으로 유지 확인도 직접 진행한다. 비밀번호 재설정 메일 수신과 본인의 새 비밀번호 입력·변경도 직접 확인한다. 모의 검증이 실제 이메일 전달·Auth 계정 생성 성공을 증명하지는 않는다.

관련 실행·설정은 [Supabase 안내](supabase-setup.md), 원격 DB 검사 재현 소스는 `supabase/tests/rls.sql`을 참고한다.

## 이메일 인증 우선 가입 변경 검증

2026-11-03, Luna low가 격리된 SDK fixture와 Edge headless로 **38/38개**를 통과했다. 콘솔·페이지 오류와 외부 요청은 모두 0건이다. 실제 계정 생성·메일 발송·실제 비밀번호 변경은 수행하지 않았다. 기존 81개 검사는 이전 가입 흐름의 기록이며, 이번 변경은 아래 별도 검사로 확인했다.

- 네 페이지 200 응답, 이메일 형식 검사, 인증 전 이름·비밀번호·완료 버튼 잠금.
- 인증 요청·재요청의 중복 클릭과 요청 제한·재시도, 임시 비밀번호가 호출 인자 외 앱 저장소·화면에 남지 않는지 확인.
- 모의 인증 세션 수신 후 입력 활성화·이메일 읽기 전용, 새로고침 후 가입 마무리 재개.
- 비밀번호 불일치·약한 비밀번호·DB 저장 실패 시 입력 보존, 완료 후 입력 초기화.
- 서버 getUser가 반환한 기존 계정·미인증 계정·다른 소유자·잘못된 대기 메타데이터·조회 오류일 때 가입 완료 요청 차단.
- 다른 탭의 로그인·로그아웃 반영, 일반 로그인·로그아웃·비밀번호 복구 회귀, 이름 특수문자 텍스트 처리.
- 모바일 가로 넘침 없음, 인증 버튼 배치 및 데스크톱·모바일 화면 확인.

실행 스크립트·결과 JSON·화면은 저장소 외부 `작업자료/Signup_Email_First_QA/`에 보관한다. 로컬 검증 서버는 종료했다. 실제 메일 링크 교환과 최종 비밀번호 로그인은 이 변경의 배포가 완료된 후 계정 소유자가 확인한다.
