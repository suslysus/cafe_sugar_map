## 제출 준비

첨부된 중간 산출물 공지 기준:

- 마감: 10월 23일 금요일.
- 보고서: PPT 형식으로 현재까지의 기능 확정·설계 결과 등을 정리한다.
- 회의록: HWP 문서.
- 소스 코드: 필수 아님, 희망 시 제출 가능.
- 제출 방식: 공지에 나온 조교에게 이메일로 직접 제출.

GitHub 반영과 이메일 제출은 별개이다. 이번 작업은 파일과 저장소 자료를 준비하며 이메일을 발송하지 않는다.

## 제출 전 보완

- 회차별 안건, 시간·장소·작성자 확인.
- 실제 구현 내역이 있으면 코드·실행 화면·검증 결과를 추가.
- 데이터 수집 출처와 지도 API·로그인 기술 선택.
- 팀이 합의한 일정 및 제출 담당자 확인.
