# 중간 산출물

- **[최신 보고서 — Figma Slides에서 열기](https://www.figma.com/slides/Np9n3FqsM4UbkmR2TywNCi)**: 12장. 중간 과제의 시스템 설계 범위에 맞춰 주제 선정·기대효과, 주요 기능·역할, 4개 화면, 실제 메뉴 예시, 데이터 연결, 활동 현황, 구축 환경을 정리한 편집 가능한 최신본. 중복 역할표·마지막 요약을 삭제했고 제출 일정은 넣지 않았다.
- `Cafe_Sugar_Map_중간보고서.pptx`: 초기 생성본. 사용자 환경의 한쇼에서 열기 실패가 확인되어 최신 보고서는 위 Figma Slides를 사용한다. 압축 구조 검사는 정상이었으며 구체적인 호환 실패 원인은 미확정이다.
- `Cafe_Sugar_Map_회의록.hwp`: 9/30·10/7·10/14 회의 이력과 최신 확정사항 종합. 회차별 세부 논의 미제공 부분을 표시함.

기준일: 2026-10-17. 웹 서비스의 구현 완료 보고서가 아니라 현재까지의 기획·설계 중간 보고 자료이다.

회의 일자·참석자·역할은 사용자 확인 내용을 반영했다. 회의 시간·장소·작성자 및 일부 회차별 안건은 제출 전에 보완해야 한다.

메뉴 예시는 [별도 출처 문서](../menu-example.md)를 참고한다. 가격은 음료 교환권 표시가이며 매장 판매가를 별도 확정한 값은 아니다. 전체 브랜드·메뉴의 데이터 수집은 완료하지 않았다.
