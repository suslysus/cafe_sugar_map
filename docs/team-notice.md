# 팀플 개발·협업 공지문

아래 내용을 카카오톡 단체방에 복사해서 공유합니다.

---

웹페이지 기초본 4개 만들어서 GitHub main에 올려뒀어요.

[GitHub 저장소](https://github.com/suslysus/cafe_sugar_map)

HTML·CSS·JS 기반이고 페이지 이동과 기본 동작만 연결한 상태입니다. 메뉴·지도는 예시 데이터이고 실제 백엔드·크롤링은 아직 연결하지 않았어요.

각자 아래 페이지 담당해서 개발하면 됩니다.

- 강민재: 지도·메뉴
- 강다은: 메뉴 검색
- 현준혁: 트렌드·신메뉴
- 한정원: 로그인·마이페이지 및 백엔드

**기초본만 main에 직접 올렸고, 앞으로는 반드시 본인 작업 브랜치에서 개발해 주세요.**

작업 브랜치에서 수정 → commit·push → main 대상으로 PR 생성 → 단톡 작업 보고·검토 요청 → 다른 팀원 확인 후 merge 순서로 진행합니다. main에서 직접 작업하거나 강제 push하지 말아 주세요.

**수정이 끝나 PR을 올리면 단톡에도 반드시 작업 내용을 공유해 주세요.** 어떤 파일에서 무엇을 고쳤는지, 기능을 추가·변경·삭제한 부분은 무엇인지, 다른 페이지에 영향이 있는지 적고 PR 링크와 검토 요청을 함께 남겨 주시면 됩니다. 여러 파일을 바꿨으면 파일별로 설명해 주세요. 기능 변경이 없는 문구·스타일·문서 수정도 공유합니다.

아래는 형식 예시입니다. 실제 작업 내용과 PR 링크로 바꿔서 올려 주세요.

> mypage.html에서 즐겨찾기 목록 안내 문구와 빈 목록 영역을 수정했습니다.
> assets/js/mypage.js에서는 저장한 메뉴가 없을 때 안내가 표시되도록 기능을 추가했습니다.
> 공통 파일 수정은 없고 마이페이지에만 영향이 있습니다.
>
> main에 merge하려고 PR 올렸습니다.
> PR: [실제 PR 링크]
>
> 시간 되시는 분 확인해 주시고, 문제없으면 GitHub에서 Approve나 확인 댓글 남겨 주세요. 단톡에도 ‘PR 확인했습니다. merge해도 됩니다’처럼 체크해 주시면 감사하겠습니다.

검토하시는 분은 변경 파일과 동작을 확인하고 결과를 남겨 주세요. 수정이 필요하면 어떤 부분인지 알려 주시고, 작성자는 보완 후 다시 확인 요청해 주세요. **다른 팀원 확인 없이 바로 merge하지 않습니다.** merge 후에도 해당 PR과 완료 사실을 단톡에 알려 주세요.

공통 CSS·JS나 메뉴 데이터 구조는 다른 페이지에도 영향이 있으니 수정 전에 먼저 공유해 주세요.
