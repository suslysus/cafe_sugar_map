## 9월 30일 — 주제 선정 및 팀 운영

1. 팀원별 아이디어 2~3개를 공유하고, 인당 2표로 후보 5개를 구체화했다.
2. 후보는 공백 시간 활용 장소 추천, 프랜차이즈 카페 영양성분 비교, 식재료 유통기한·수량 관리, 대학생 생필품 공동구매 지도, 공용 화장실 위치·리뷰 서비스였다.
3. 교수님의 설명을 바탕으로 카페 메뉴 당류 비교 서비스를 선정했다.
4. 현재 위치와 가까운 카페를 지도에서 확인하고 메뉴별 당류를 비교하는 방향을 정했다.
5. 브랜드 선정과 칼로리 정보 추가는 이 시점에는 검토 사항이었다.
6. 팀장은 한정원, 회의는 주 1회, 회의록은 순번제로 작성하기로 했다.

근거: 기존 ‘팀프로젝트 지도 활동보고서 1.hwp’. 연락처와 서명은 공개 저장소에 옮기지 않았다.

## 세 회의 이후 최신 확정사항 종합

아래 내용은 사용자가 전달한 최신 합의사항이며, 각 항목이 결정된 정확한 회차는 구분하지 않았다.

### 1페이지 — 강민재

- 현재 위치를 요청하고 숭실대를 기본 위치로 사용한다.
- 왼쪽 지도, 오른쪽 카페 메뉴 정보로 구성한다.
- 컴포즈커피·스타벅스·할리스·메가커피를 대상으로 한다.
- 메뉴 이름·가격·당류·칼로리를 가장 작은 사이즈 기준으로 표시한다.
- 메뉴 선택 시 상세 정보를 제공한다.
- 옵션 처리 방식은 미정이며, 옵션 추가 시 정보가 변경될 수 있음을 표시한다.
- 길 안내는 추후 추가한다.

### 2페이지 — 강다은

- 카테고리 기반 검색과 브랜드 선택을 제공한다.
- 최신 수정 방향: ‘비교에 추가’는 1페이지에서 2페이지로 옮겨 배치할 예정이다.
- 카테고리: 카페인, 디카페인, 요거트, 아이스크림&빙수, 라떼, 프라페&스무디, 과일.
- 즐겨찾기는 로그인한 사용자만 사용할 수 있게 한다.
- 별도 장바구니·비교 기능은 시간이 남으면 추가한다.

### 3페이지 — 현준혁

- 브랜드 → 카테고리 순으로 선택한다.
- 조건에 해당하는 음료 중 하나를 무작위 추천한다.

### 4페이지 — 한정원

- 로그인 화면을 만든다.
- 즐겨찾기한 음료 목록을 보여준다.
- 위치 등 권한 상태를 확인할 수 있게 한다.

## 후속 논의 항목

- 지도 API, 로그인·데이터 저장 방식, 공식 메뉴 정보 수집 방식.
- 최소 사이즈·온도·단위 기준과 카테고리 중복 처리.
- ‘비교에 추가’의 표시 방식과 별도 비교 기능의 범위.
- 옵션별 변경값 제공 여부, 사용자에게 요청할 추가 권한 종류.
- 회의 시간·장소·회차별 작성자와 상세 논의 기록 보완.

담당자는 위 페이지별 분담에 따른다. 후속 일정은 제안 단계이며 별도 합의가 필요하다.
