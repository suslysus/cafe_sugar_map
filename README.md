# Cafe Sugar Map

지도 기반 주변 프랜차이즈 카페 메뉴 당류 비교 웹 서비스

## 프로젝트 소개
현재 위치 주변의 프랜차이즈 카페를 지도에서 확인하고,
카페별 메뉴의 당류 함량을 비교하여 음료 선택을 돕는 서비스입니다.

## 주요 기능
- 지도에서 현재 위치 주변 카페 확인
- 주변 카페의 메뉴 및 당류 정보 조회
- 카페별 메뉴의 당류 함량 비교

## 검토 중인 사항
- 칼로리 정보 추가 비교
- 스타벅스, 메가커피, 컴포즈커피, 할리스 등 비교 대상 선정

## 팀 운영
- 팀장: suslysus
- 정기 회의: 주 1회
- 회의록: 팀원들이 순서대로 돌아가며 작성

## 진행 현황
- 팀원별 아이디어 2~3개 제안
- 인당 2표씩 투표하여 후보 5개 구체화
- 교수님의 설명을 바탕으로 카페 당류 비교 서비스 선정
- 지도 기반 주변 카페 메뉴 비교를 핵심 기능으로 결정
