# Cafe Sugar Map

지도에서 주변 프랜차이즈 카페를 찾고, 메뉴의 가격·당류·칼로리를 확인하는 웹 서비스입니다.

웹프로그래밍 **13조** · 중간 산출물 기준일: **2026-10-17**

> 현재 단계는 기능 확정 및 설계입니다. 이 저장소에는 기획 문서와 중간 보고 자료를 정리하며, 서비스 구현 코드는 아직 등록되지 않았습니다.

## 대상 브랜드와 정보 기준

- 컴포즈커피, 스타벅스, 할리스, 메가커피
- 메뉴 이름, 가격, 당류, 칼로리를 표시합니다.
- 사이즈는 각 메뉴의 **가장 작은 사이즈**를 기준으로 합니다.
- 메뉴를 누르면 상세 정보를 보여줍니다.
- 옵션 처리 방식은 미정이며, **“옵션 추가 시 가격 및 영양정보가 변경될 수 있습니다.”**라고 안내합니다.

## 페이지 구성과 담당

| 페이지 | 주요 내용 | 담당 |
| --- | --- | --- |
| 1. 지도·메뉴 | 현재 위치 요청, 위치 미제공 시 숭실대 기준 시작, 왼쪽 지도·오른쪽 메뉴 정보 | 강민재 |
| 2. 카테고리 검색 | 카테고리·브랜드로 메뉴 탐색, 로그인 기반 즐겨찾기, ‘비교에 추가’ 배치 예정 | 강다은 |
| 3. 랜덤 추천 | 브랜드 → 카테고리 → 조건에 맞는 음료 하나 추천 | 현준혁 |
| 4. 로그인·마이페이지 | 로그인, 즐겨찾기 음료 목록, 위치 등 권한 상태 확인 | 한정원 |

카테고리: **카페인 / 디카페인 / 요거트 / 아이스크림&빙수 / 라떼 / 프라페&스무디 / 과일**

## 추가 구현 및 미정 사항

| 구분 | 내용 |
| --- | --- |
| 추후 추가 | 길 안내 |
| 시간 여유 시 추가 | 별도 장바구니·비교 화면 |
| 구현 방식 미정 | 비교에 추가한 메뉴를 보여주는 방식, 옵션 처리, 지도 API, 로그인·저장 방식 |
| 데이터 확인 필요 | 브랜드별 공식 가격·영양정보, 최소 사이즈, 갱신 기준 |

‘비교에 추가’는 **2페이지에 배치하는 방향**으로 정리했습니다. 별도 비교함·장바구니·비교 화면은 현재 필수 범위로 확정하지 않았습니다.
